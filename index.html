How it works

1. Predict. A small neural network reads the rain forecast (depth, duration, timing of the peak, intensity), the tank level and the drain capacity. It estimates the chance of street flooding and the peak drain flow if nobody acts.

2. Plan. An optimiser runs this prototype's own simulation many times to find the smallest pre-storm release that keeps the drain safe, with a 10% margin for forecast error. Light rain means tanks stay full, so more water is kept for dry spells.

The model was trained in Python with scikit-learn on 40,000 storms generated by this prototype's simulation engine, including forecast errors of up to ±20%. It used an 80/20 train/test split. It runs in the browser with no server.

Limits

Trained only on synthetic data from this prototype's simulation, so it is only as good as the model's assumptions.

A pilot would retrain the network on real rainfall forecasts (MetMalaysia), observed rainfall and drain-sensor data before it controls real tanks.

Data integrity statement. This prototype uses synthetic data based on stated assumptions. No proprietary or live data is used. The storm is a synthetic triangular rainfall pattern; homes, roofs, tanks and drain capacity are assumed values for a typical Shah Alam terrace neighbourhood. How the model works

1. Rain: a synthetic storm is split into 5-minute steps, peaking about 35% into the storm.
2. Runoff: rainfall × area × runoff coefficient (Rational Method). Roofs drain to tanks or drains; roads and driveways drain straight to the drain.
3. Without RainBank: tanks are full or absent, so all roof water reaches the drain.
4. Normal tanks: start half-full and fill from the first drop, often full before the peak arrives.
5. RainBank: empties tanks to the reserve level over 3 h before the storm, then uses the forecast to capture the highest roof inflows (peak shaving). After the storm, zones release down to the keep level one at a time, downstream first, keeping the drain below 50% capacity.
5b. AI planner (default): instead of always emptying to the reserve slider value, the AI planner picks the reserve for each storm (never below 20%). Turn it off on the Storm Simulation tab to use the fixed rule. See the AI Model tab.
6. Drain: inflow is smoothed with a linear-reservoir routing step; flow above capacity is counted as street flooding.
