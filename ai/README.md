# RainBank AI: Predict → Plan

## 1. Predict: flood-risk neural network
- **What it predicts:** the chance of street flooding, and the peak drain flow, **if nobody acts** (today's passive tanks), about 3 hours before a storm.
- **Inputs:** forecast rain depth, storm duration, timing of the rain peak, tank level, drain capacity per 100 homes, plus two engineered features (rain intensity in mm/h, and rain relative to drain capacity).
- **Model:** scikit-learn MLP (64 → 32 neurons). A classifier gives flood probability; a regressor gives peak flow.
- **Data:** 40,000 synthetic storms generated by the prototype's **own** simulation engine (`engine_from_index.js`, copied from `index.html`). The actual storm differs from the forecast by about ±20%, so the model learns realistic probabilities. Split 80/20 train/test.
- **Test results (8,000 unseen storms):** accuracy 93.3% · AUC 0.985 · peak-flow R² 0.89 (mean error ±19%).
- **Calibration check (default neighbourhood):** 50 mm storm → model 83% vs simulated 77% · 35 mm burst → model 85% vs simulated 89% · 20 mm → model 0% vs simulated 0%.

## 2. Plan: AI release planner
- **Problem with the old rule:** it empties every tank to 20% before every storm, even light rain.
- **What the planner does:** it tests release levels using the simulation and picks the **highest reserve (smallest release)** that keeps a forecast storm 10% bigger than predicted at or below 90% of drain capacity.

| Storm | Old fixed rule | AI planner |
|---|---|---|
| 20 mm light rain | Empties to 20%, no flood | **Keeps 100%**, no flood (+320 m³ kept) |
| 50 mm heavy | Peak 321 L/s, 0 m³ flood | Same decision and result |
| 35 mm burst / 80 mm extreme | Release max | Same decision, and warns residents early |

## Reproduce
```
node generate_data.js 40000 > storms.csv
python3 train_model.py storms.csv model.json
# then rebuild rainbank-ai.js: replace /*MODEL*/ in rainbank-ai.template.js with model.json
```

## Data integrity
All training data is synthetic, generated from the prototype's stated assumptions. No real or proprietary data is used. A pilot would retrain the model on real rainfall (MetMalaysia, JPS) and drain flow-sensor data.
